# VR Box AR - El takibi ile AR eşyalar

- ARCore: kamera + oturum
- MediaPipe Hand Landmarker: el takibi (model GitHub Actions'ta indirilir)
- VR Box için yan yana çift göz (stereo) çıkış, sabit (head-locked) cam menü
- Menü: işaret parmağı = imleç, başparmak+işaret çimdiği = seç. Test için ekrana dokunmak da çalışır.

Derleme: GitHub'a push -> Actions "apk" -> Artifacts içinden vrbox-ar-debug-apk
